Chat commands

Run these in your Twitch chat. Only the broadcaster and moderators can run them — everyone else is silently ignored.

On / off / status

!parrot on

Resume posting.

!parrot off

Pause posting. Resets to on whenever the bot restarts.

!parrot stats

Replies with today's seen / kept / posted / blocked / token counts.

!parrot help

Replies with a link to this page.

Update the knowledge base from chat

Quick edits without leaving stream. Five fixed paths can be set without quotes:

!parrot set bio "I climb and play PoE2"

Update your bio.

!parrot set game World of Warcraft Classic

Update what you're playing.

!parrot set schedule Mon-Fri 7pm PT

Update when you stream.

!parrot set identity.name Mathew

Update your name.

!parrot set identity.pronouns he/him

Update your pronouns.

For custom fields, Q&A, and links — these update an existing entry by label. Add new entries via the dashboard:

!parrot set field "Build" https://wago.io/abc

Update a custom field by label.

!parrot set qa "What's your setup?" 3090, 5800X

Update a Q&A entry by question.

!parrot set link "LinkedIn" https://linkedin.com/in/...

Update a link entry by label.

Quiet things down

!parrot ignore <intent> [minutes]

Stop answering this intent for N minutes (default 5). Intent IDs are visible in the activity log — they look like "current_game" or "custom_qa:qa_3".

!parrot ban <username>

Ignore everything from this user for the rest of the session. Resets on bot restart.

What the bot can't do

  • Ban, time out, or delete chat messages
  • Read whispers
  • Read other channels
  • Add new custom fields, Q&A, or links from chat (use the dashboard)

Bot replies to commands obey the same on/off and shadow-mode flags as normal answers — if posting is paused, command confirmations are paused too. Toggle with !parrot on.
